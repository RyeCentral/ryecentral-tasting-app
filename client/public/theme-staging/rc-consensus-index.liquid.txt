  RyeCentral Consensus Index — step 10, phase 1 (Sep 2026).

  TASTING QR CODES (25 Oct 2026, revised 25 Oct: one bottle at a time, no
  bulk sheet — Kevin; moved to its own far-right "QR" column the same day).
  Each row has an empty td.rc-ci-qrc in the source (so the column never shifts
  the layout) that script fills with a QR icon button, which opens that
  ONE bottle's QR window (tube / bottle-back preset, width, copies, Print,
  SVG, PNG). They are BUTTONS (no crawlable links) injected by script, so the
  page's HTML, links and structured data are unchanged. The
  generator (assets/rc-ci-qr.js, ~35 KB) loads only on first tap. Codes encode
  HTTPS://WWW.RYECENTRAL.COM/T/{first 6 hex of md5(handle)}; every /t/ path
  is a Shopify URL redirect to the noindex router /pages/taste?h={handle},
  which forwards into the tasting app (the app host lives on that page only,
  so printed codes survive a host change). A new review needs its /t/
  redirect added; without it the generator falls back to the longer URL and
  warns. Read the header of assets/rc-ci-qr.js before changing the code scheme
  — anything already printed depends on it.

  Live from the review products' ryecentral.* metafields. There is no second
  copy of the data: every cell is read at render time, so the page can never
  disagree with a review page or the tracker.

  Publishes DERIVED fields only: score /5, published-ratings count, source
  count, confidence band + percent, last verified, the change at the latest
  reading and its public note. Per-source values never leave Audit Master.

  Structured data: Dataset + ItemList linking every row to its review. The
  score is NEVER placed in aggregateRating / Review — it is a compiled
  figure, not a user rating (see the review-schema fix, Sep 2026).

  Data terms (decided 14 Sep 2026, revised 22 Oct 2026): proprietary, quoting
  with attribution welcome; search engines and AI systems may read, index,
  cite and TRAIN on the public pages (Kevin, 22 Oct 2026 — the TDMRep
  reservation was removed from meta-tags.liquid the same day); copying or
  scraping the dataset to republish / rebuild / resell it, use inside a
  product, database or ranking only under a data-partner licence. Free API +
  MCP access (phases 2-3, 22 Oct 2026, /pages/consensus-api) needs a free key and
  the citation shown with every score; CSV = personal evaluation licence. The CSV sits behind a click-through agreement: the form posts to
  Shopify as a normal customer signup (tags consensus-data-terms /
  consensus-terms-v1 / consensus-use:* / csv:<id>) so the assent is recorded
  server-side BEFORE the file is delivered; Shopify returns the visitor with
  customer_posted=true and only then does the download fire, carrying the
  download ID and licensee email on every row. Do not switch this to a
  background fetch or a hidden iframe — /contact is captcha-gated and both
  fail silently, leaving a download with no agreement behind it (tested
  14 Sep 2026). No public JSON view — phase 2 serves partners through the
  Worker with keys.

  Confidence vocabulary (19 Sep 2026): the public words are EARLY / SOLID /
  STRONG, EARLY lowest. A row prints the band word STRAIGHT FROM the
  `consensus_confidence` metafield, so this page can never disagree with a
  review page or the badge — never hardcode a band word into a row, change the
  data. Colour, counters, chips and filters run off an internal tier key
  (high / medium / low, unchanged so the CSS did not have to move) that accepts
  BOTH vocabularies — strong|high, solid|medium, early|low — and falls back to
  the composite (>=80, >=60, else) if a word is ever unrecognised. That is what
  lets the metafields migrate after this is published instead of in lockstep.
  The fourth state is Unverified: a score compiled at creation with no engine
  reading behind it. Its label is set once in `baseline_label` below.

  SEO deploy (20 Oct 2026) — Primary keyword "rye whiskey ratings":
  * Rows are now SORTED SERVER-SIDE by score (ties by ratings count) and the

    without JavaScript. The sort is done in Liquid by prefixing every captured

  * The ItemList is now ItemListOrderDescending with positions following rank.
  * A "Highest-rated at Strong confidence" block (top 5 Strong-band rows by

  * The H1 falls back to the page title when the section heading is blank

  * Every score quoted in prose keeps the reserved form

{%- capture faq_q1 -%}What is the highest-rated rye whiskey right now?{%- endcapture -%}
{%- capture faq_a1 -%}{%- if top1_name != blank -%}As of {{ last_verified }}, the highest-rated rye whiskey in this index at Strong confidence is <a href="/products/{{ top1_handle }}">{{ top1_name }}</a>, with a RyeCentral Consensus Score {{ top1_score }}/5 compiled from {{ top1_srcs }} sources at {{ top1_pct }}/100 confidence. {%- capture faq_q2 -%}How are these rye whiskey ratings compiled?{%- endcapture -%}
{%- capture faq_a2 -%}Each RyeCentral Consensus Score is compiled from the published ratings and critic reviews for that bottle, weighted by sample size and source quality and filtered to exclude brand copy and paid tastings. It is a derived figure, not a user rating, which is why it never appears in review-rating structured data. The per-source workings stay internal; the index publishes the score, the published-ratings count, the number of sources counted and the confidence behind the number. <a href="/pages/review-methodology#consensus-score">Full methodology →</a>{%- endcapture -%}
{%- capture faq_q3 -%}What does the confidence rating mean?{%- endcapture -%}
{%- capture faq_a3 -%}Confidence is a composite out of 100 built from source count, source quality, sample size, agreement between sources, stability across readings and the depth of flavour evidence. Strong is 80 or above, Solid is 60–79 and Early is below 60. {{ baseline_label }} rows carry the score as first compiled and are queued for their first verified reading. <a href="/pages/review-methodology#confidence">Confidence explained →</a>{%- endcapture -%}
{%- capture faq_q4 -%}How often do the rye whiskey rankings change?{%- endcapture -%}
{%- capture faq_a4 -%}Every bottle is re-verified on a rolling 60-day cycle. A published score only moves when a new reading differs by 0.1 or more, and on Early evidence it can fall but not rise, so the rankings shift when the evidence does, not with every new review. The Change column shows the movement at the latest reading and, where a score moved, a short note explaining why.{%- endcapture -%}
{%- capture faq_q5 -%}Is this the same as the best rye whiskey list?{%- endcapture -%}
{%- capture faq_a5 -%}No. This index is every rye whiskey RyeCentral has reviewed, in every confidence band, with the evidence behind each score. The <a href="/collections/community-top-rated-rye-whiskey">50 Top-Rated Rye Whiskeys</a> list is the shortlist drawn from it: the highest-scoring bottles at Solid or Strong confidence only. Start there to choose a bottle; come here to see how any bottle's score was earned.{%- endcapture -%}
